# Components Directory

This directory contains reusable UI components that can be used throughout the application.

## Guidelines

- Components should be pure and reusable
- Each component should be self-contained in its own file
- Use PropTypes or JSDoc for prop documentation
- Keep components small and focused on a single responsibility

## Examples

- `Button.jsx` - Reusable button component with variants
- `Card.jsx` - Card container component
- `Navbar.jsx` - Navigation bar component
