# Pages Directory

This directory contains page-level components that correspond to routes in the application.

## Guidelines

- Each page should be a separate component file
- Pages are connected to routes in App.jsx
- Pages can compose multiple components and features

## Current Pages

- `Home.jsx` - Landing page
- `About.jsx` - About page
- `Dashboard.jsx` - Dashboard page
- `NotFound.jsx` - 404 error page
